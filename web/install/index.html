Flotaryx on your home screen.

Install the web app directly from your browser. Sign in using your existing Flotaryx account.

Open Flotaryx

iPhone / iPad

  1. Open Flotaryx in Safari (not a private tab).
  2. Tap Share (or Page Menu, then Share).
  3. Select Add to Home Screen.
  4. Keep Open as Web App enabled, then tap Add.

Android

  1. Open Flotaryx in Google Chrome.
  2. Tap the Chrome menu (⋮).
  3. Choose Install app or Add to Home screen.
  4. Confirm installation, then sign in.

This is an installable web app (not a native App Store or Google Play release). It needs internet access for company data and checks. Managers can also work directly from the web portal.
